Upload Instructions

  1. Go to entra.microsoft.com and sign in
  2. Navigate to User experiences → Company branding
  3. Click Configure (or Edit if already configured)
  4. Under Sign-in form:
    • Banner logo → upload axeum-banner-logo.png
    • Square logo (light) → upload axeum-square-logo.png
    • Square logo (dark) → upload axeum-square-logo-dark.png
    • Background image → upload axeum-background.png
    • Favicon → upload axeum-favicon.png
  5. Under Sign-in page text, enter: Axeum Technologies — Orchestration Governance
  6. Set Page background color to #1A1A1A
  7. Click Save
